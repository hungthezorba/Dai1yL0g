## Project Summary

**Dai1yL0g** is a private, friend-first social mobile app for capturing very short video moments throughout the day and automatically compiling them into one **daily vlog** at day end—without manual editing.

Target users: people who want casual, authentic sharing with close friends (BeReal / Snapchat energy), not polished long-form content.

Primary differentiation vs Setlog:

1. **Reliable export** — compiled vlogs save/share with **audio intact**.
2. **Scale-safe stitching** — many clips per day must not crash export or compile.
3. **Android parity** — smooth capture, stitch, and export on Android, not iOS-only quality.

## Architecture Questions

Resolved in `docs/decisions/0006-dai1yl0g-product-stack.md` and `docs/decisions/0007-dai1yl0g-vlog-compilation-strategy.md`. Summary:

- **Runtime (client):** Expo SDK 56, React Native, development builds (camera + native modules).
- **Surfaces:** iOS and Android mobile; web out of MVP scope.
- **Storage:** Object storage for clips and compiled vlogs; Postgres for social graph and metadata.
- **Video processing:** FFmpeg on-device primary; optional server fallback for failed or oversized jobs.
- **Realtime:** WebSocket or BaaS realtime for feed and chat.
- **Security:** Private-by-default audiences; signed upload URLs; parse-first API boundaries per `docs/ARCHITECTURE.md`.
